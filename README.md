# 《宝可梦》第六世代汉化修正补丁
## 基本说明

本补丁是对《宝可梦 X／Y／欧米伽红宝石／阿尔法蓝宝石》汉化版的修正补丁，基于起航汉化组制作的“精灵宝可梦”版汉化版制作，感谢他们用心的汉化，汉化历程可以参考：<https://www.bilibili.com/read/cv13226711>。

修改内容主要包括：

- 将文本翻译与最新的官方中文版本游戏匹配。
- 对于英文版及宝可梦名字选择日文的情况，将连接交换的宝可梦名字及初训家名字均修改为对应语言版本的原文。

补丁中仅包含了文本和字体的改动，没有修改图片，因此部分图片中的译名可能与文本中的译名不一致。

## 使用方式

本补丁不包含游戏本体，请自行安装起航汉化组制作的《宝可梦 X／Y／欧米伽红宝石／阿尔法蓝宝石》汉化版。

对于 3DS 主机，请确保安装了最新的 [Luma3DS](https://github.com/AuroraWright/Luma3DS)，并开启了“启用游戏补丁”（Enable game patching）选项。可以通过在开机时按住 <kbd>Select</kbd> 键来确认该选项是否已开启。将压缩包中的文件夹解压到 SD 卡下的 `luma/titles/` 目录下（如果没有该目录，请自行创建）。然后通过主机的主菜单启动游戏即可。

对于 Citra 模拟器以及基于 Citra 开发的其他模拟器，请将压缩包中的文件夹解压到相应的游戏目录下，然后通过模拟器启动游戏即可。

Title ID 对应的游戏：

- `0004000000055D00`：《宝可梦 X》
- `0004000000055E00`：《宝可梦 Y》
- `000400000011C400`：《宝可梦 欧米伽红宝石》
- `000400000011C500`：《宝可梦 阿尔法蓝宝石》
